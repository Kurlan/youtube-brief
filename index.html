API setup (OAuth client ID)

In Google Cloud enable the YouTube Data API v3, then create an OAuth client of type Web application with this page's origin as an authorized JavaScript origin. The client ID is a public identifier; no client secret is used by this app.

Prefer not to paste it every time? Copy config.example.js to config.js (git-ignored) and set your client ID there.
